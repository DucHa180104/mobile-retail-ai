# MERN Phone Store

Project MERN don gian cho do an ban dien thoai.

## Cau truc thu muc

```text
mobile-retail-ai/
  client/   Frontend React + Vite
  server/   Backend Node.js + Express
```

## Yeu cau

- Node.js
- MongoDB local hoac MongoDB Atlas

## Chay backend

```bash
cd server
npm install
copy .env.example .env
npm run dev
```

Backend chay tai:

```text
http://localhost:5000
```

Neu chua co MongoDB, backend van chay nhung se bao thieu `MONGODB_URI`.

## Chay frontend

Mo terminal khac:

```bash
cd client
npm install
npm run dev
```

Frontend chay tai dia chi Vite hien thi trong terminal, thuong la:

```text
http://localhost:5173
```

## Ghi chu

Thu muc `backend` cu van duoc giu nguyen. Project moi theo yeu cau nam trong `client` va `server`.
