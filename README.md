# MERN Phone Store

Project MERN don gian cho do an ban dien thoai.

## Cau truc thu muc

```text
mobile-retail-ai/
  backend/  Backend Node.js + Express
  client/   Frontend React + Vite
```

## Yeu cau

- Node.js
- MongoDB local hoac MongoDB Atlas

## Chay backend

```bash
cd backend
npm install
npm run dev
```

Backend chay tai:

```text
http://localhost:5000
```

Can tao file `.env` trong thu muc `backend` va cung cap `MONGODB_URI` hop le.

## Chay frontend

Mo terminal khac:

```bash
cd client
npm install
npm run dev
```

Frontend chay tai dia chi Vite hien thi trong terminal, thuong la:

```text
http://localhost:5173
```

## Ghi chu

Project hien tai su dung `backend` cho Express API va `client` cho React frontend.
